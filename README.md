# 🛡️ Secure Password Generator

A robust Python-based tool designed to generate cryptographically strong, random passwords. This project demonstrates best practices in Python security and user-oriented design.

## 🚀 Features
- **Cryptographically Secure:** Uses Python's `secrets` module for high-entropy randomness (safer than the standard `random` library).
- **Guaranteed Complexity:** Automatically ensures a mix of uppercase, lowercase, numbers, and special characters.
- **Customizable:** Users can specify the desired length and number of passwords.
- **Input Validation:** Handles user errors gracefully to prevent crashes.

## 🛠️ Built With
- **Python 3.x**
- **Secrets Module:** For generating secure tokens.
- **String Module:** For character set management.
